SLIDE 2: SYSTEM OVERVIEW

MatchScore combines resume building and job-fit evaluation in one workspace.

The user can:
- Create, upload, and edit a resume
- Paste a job posting
- Compute a deterministic match score
- Review matched, missing, and partial terms
- Receive recommendations and improve the resume
- Re-score the updated resume and save the result

The main value is a single workflow from resume creation to job application
readiness.

SLIDE 4: TECHNOLOGY USED

Frontend:
- React 19, TypeScript, Vite, and CSS

Backend:
- Python and Flask REST API

Data and authentication:
- Supabase email/password authentication
- Supabase persistence and row-level security

Analysis and AI:
- scikit-learn
- TF-IDF vectorization and cosine similarity
- Google Gemini for explanations and recommendations

Document processing supports PDF, DOCX, and TXT files, with PDF export.


SLIDE 5: IMPLEMENTED FEATURE LIST

Build:
- Resume upload and parsing for PDF, DOCX, and TXT
- WYSIWYG resume editor and formatting tools
- Built-in templates and AI-generated layouts
- PDF export

Match:
- Job title and company detection
- Deterministic 0-100 match score
- Matched, missing, and partial skill terms

Improve:
- AI score explanation
- Section-targeted recommendations
- Apply one recommendation or improve the entire resume
- Automatic re-scoring after improvement

Manage:
- Supabase authentication
- Saved documents and score history
- Search, notifications, and dark mode
